# This is my first of many projects in my software engineering study plan.

This is a CLI calculator converter built with Python.

It converts the following: Mass, Temperature, Area, Length, Volume, Time, Speed.

## Mass
This converts kilograms (kg), grams (g), and pounds (lb).

## Temperature
This converts Celsius (C), Fahrenheit (F), and Kelvin (K).

## Area
This converts Hectare(ha), acre, Square Kilometer(km2), Square Meter(m2), and Square Mile(mi2).

## Length
This converts Meters (m), Kilometers (km), Inches (in), Foot (ft), Yard (yd), and Miles (mi).

## Volume
This converts Liters (L) and Gallons (gal).

## Time
This converts Seconds (s), Minutes (min), and Hours (h).

## Speed
This converts Meters per Second (m/s), Kilometers per Hour (km/h), Miles per Hour (mph), and Knot.

# HOW TO USE
* Install the latest Python from [Python offical website](https://www.python.org/downloads/).
* Clone this repository
* Open your terminal and run this command `py main.py`
* Voila!!! You can start using the calculator converter.
