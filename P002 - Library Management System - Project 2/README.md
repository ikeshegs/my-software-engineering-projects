# This is my second project in my software engineering study plan.

This is a CLI Library Management System built with Python.

It has the following functions:

1. Add Book
2. Remove Book
3. View All Books
4. Add Member
5. Remove Member
6. Borrow Book
7. Return Book
8. Exit

# HOW TO USE
* Install the latest Python from [Python offical website](https://www.python.org/downloads/).
* Clone this repository
* Open your terminal and run this command `py main.py`
* Voila!!! You can start using the Library Management System.
